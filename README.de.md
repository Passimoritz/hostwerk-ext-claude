# Claude

Claude mit Hostwerk: Claude Desktop und Claude Code verbinden, direkt im Projekt loslegen, Tokens sparen und mit Tipps & Tricks bessere Ergebnisse bekommen.

Eine offizielle [Hostwerk](https://github.com/Passimoritz/hostwerk-public)-Erweiterung (SDK 2.5). Der Motor bleibt in Hostwerk, diese Erweiterung ist seine Oberfläche.

## Reiter

- **Loslegen:** Projekt wählen, Auftrag beschreiben (oder Vorlage wie *Fehler beheben*, *Tests schreiben*). Hostwerk öffnet Claude Code im Projektordner und tippt den Befehl ins Hostwerk-Terminal, du startest ihn mit Enter. Claude Code, Claude Desktop und Claude im Browser lassen sich von hier aus installieren.
- **Verbinden:**
  - Claude Desktop und Claude Code mit dem Gedankennetz verbinden (MCP);
  - Kontext in die Dateien anderer KI-Werkzeuge schreiben (`CLAUDE.md`, `.cursorrules` …);
  - Wissensgraph öffnen oder den Kontext für claude.ai kopieren.
- **Token sparen:**
  - Verbrauch je Tag als Diagramm, mit Trend;
  - Spar-Werkzeuge aus dem Online-Katalog, per Klick installiert und aktuell gehalten, mit Vor- und Nachteilen und Vergleich;
  - neu entdeckte Projekte auf GitHub.
- **Tipps & Tricks:** durchsuchbare Karten in vier Bereichen (Kontext klein halten, gute Aufträge, Tasten & Befehle, mit Hostwerk). Befehle lassen sich mit einem Klick kopieren.
- **Protokoll:** was ein verbundenes Claude gelesen und sich gemerkt hat.
